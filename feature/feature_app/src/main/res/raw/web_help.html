Local Signage 使用手册

本地优先、无需账号的 Android 广告屏管理与播放指南

快速开始内容与场景播放列表网页与 H5多设备显示设置故障排查

快速开始

  1. 让广告机和控制手机或电脑连接同一个局域网。
  2. 扫描广告机上的二维码，或在浏览器打开屏幕显示的局域网地址。
  3. 输入六位配对码并接管控制。
  4. 从“发送”页上传图片、视频、文字或网页，然后创建播放列表。

素材与排期保存在广告机本地。浏览器关闭后，播放不会中断。

内容与场景

资源是图片、视频、文字或网页；场景决定画面适配、背景和字幕叠加。使用完整显示时，可为本地图片启用模糊背景。跑马灯支持位置、字号、颜色和速度设置。

播放列表

在“内容 → 播放列表”中新建排期。拖动项目可调整顺序，也可以使用上下按钮完成键盘操作。图片项目可设置停留秒数。

网页、HTML 与 H5 项目包

远程网页必须使用 HTTPS。单文件 HTML 可直接编辑并预览；完整 H5 项目可上传 ZIP，根目录必须有 index.html，最多 256 个文件、50 MB。项目在应用私有目录离线运行。

多设备

Pro 用户可以发现、配对和同步同一局域网内的其他屏幕。设备不会暴露到公网，也不依赖云端账号。

显示设置

设备设置提供屏幕常亮、启动恢复、全屏播放，以及自动、横屏或竖屏方向。方向改变会重建播放界面，播放服务继续运行。

故障排查

浏览器打不开控制台

确认设备位于同一 Wi-Fi，地址包含端口，并检查路由器是否启用了 AP 隔离。

画面有黑边

选择铺满或裁切模式；本地图片在 Android 12 以上还可以使用模糊背景。

重启后没有自动播放

确认已启用启动恢复，并在系统设置中允许应用自启动和后台运行。
