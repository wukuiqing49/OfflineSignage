# 专用展示设备启动与恢复

1. 在应用“使用说明”中打开“开机自启动与后台守护”，点击页面底部设置按钮。
2. 阅读“专用展示设备启动”说明，选择“主屏幕应用设置”，再由系统确认Local Signage为默认主屏幕。普通手机可取消；应用不会替用户选择。
3. 在控制台设置开启“启动后恢复播放”，准备素材并开始播放。之后Home键进入本应用，系统在开机/解锁后启动默认主屏幕时可恢复播放。
4. 返回原桌面：再次从同一帮助入口选择“主屏幕应用设置”，在系统Home列表选回原启动器；也可直接进入系统默认应用设置。

此模式不是锁定桌面、Device Owner或自动解锁。密码锁设备仍须解锁，管理员或厂商可限制默认Home选择。原播放暂停时不强制改为播放；未启用启动恢复时不强制恢复。厂商自启动与后台设置仍有独立入口。

Android15+仍保留开机广播直接启动媒体前台服务的限制。本实现让系统启动用户选择的Home前台入口，再走原有播放恢复路径。参考[Android前台服务后台启动限制](https://developer.android.com/develop/background-work/services/fgs/restrictions-bg-start)和[系统Home角色](https://developer.android.com/reference/android/app/role/RoleManager#ROLE_HOME)。

本轮Android36隔离模拟器已验证强制掉电、禁用快照冷启动、无需手动打开应用的视频恢复及切回原桌面；Pixel8只验证正式包设置入口、取消与普通播放，未更改其默认桌面。实体机断电、其他厂商、受管理设备及锁屏无人值守仍需部署现场验证。
