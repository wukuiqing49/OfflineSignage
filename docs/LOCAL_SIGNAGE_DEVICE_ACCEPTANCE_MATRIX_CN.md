# 设备与现场验收矩阵

日期：2026-10-29。下列项目均为待执行清单，不是通过证明。

## 支持边界

| 设备类型 | 恢复行为 | 本轮现场结论 |
|---|---|---|
| Android 15/16 普通手机、平板 | 重启后手动打开应用，再按设置恢复播放 | 未执行 |
| Android 12–14 普通设备 | 存在开机恢复路径，但受厂商后台/启动策略影响 | 未执行 |
| 专用广告机、Android TV/盒子 | 需厂商自启动、Launcher/Kiosk 或设备管理配置，并按型号验收 | 未执行 |

最低系统配置以版本目录 minSdk 为准；表格不是对未列出系统的兼容承诺。内容同步和统一播放不代表逐帧同步。

## 每台验收设备必须记录

机型、系统/API、固件版本、解码能力、分辨率与方向、输入方式、网络拓扑、供电策略、应用版本、APK SHA-256、签名/安装来源、时间、步骤、观察、证据位置和问题编号。报告不记录真实 Token、账号或客户素材。

| ID | 场景 | 通过条件 | 状态 |
|---|---|---|---|
| FIELD-BOOT | 播放中断电，再通电 | 符合该设备声明的恢复等级；记录恢复时间，无错误承诺 | 未执行 |
| FIELD-OFFLINE | 关闭浏览器、断开网络 | 已落盘内容继续播放；网络内容有重试或兜底 | 未执行 |
| FIELD-GATEWAY | 两台真机同步后关闭网关 | 目标设备独立播放，网关恢复后能重新管理 | 未执行 |
| FIELD-GROUP | 组内一台离线或磁盘满 | 显示逐台结果，失败不影响成功设备，重试不重传新内容或误播本机 | 未执行 |
| FIELD-ENDURANCE | 24 小时图片/视频/HTML 混播 | 无未恢复黑屏、ANR、服务中断；记录内存、温度、错误与存储变化 | 未执行 |
| FIELD-STORAGE | 低存储、上传中断、损坏媒体 | 原有播放不被破坏，有明确错误及可恢复操作 | 未执行 |

| FIELD-PLAY | Play 测试轨购买/恢复/取消/退款 | 实际商品、价格及权益变化正确；不以 UI 夹具代替真实交易 | 未执行 |
