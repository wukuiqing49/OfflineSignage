# 第三方社交平台宣传素材规格与规范 (Social Media Assets Spec)

本 Skill 专门沉淀 **Twitter (X)、抖音 / TikTok、Reddit、YouTube Shorts** 等主流三方平台的**硬性尺寸、画面比例、安全区遮挡避让与社区调性红线**。具体展示的商业案例、创意脚本与宣传文案，由用户按需填充或与 AI 动态协作定制。

---

## 一、 主流三方平台硬性尺寸与比例矩阵

各平台的展现逻辑与裁切规则差异极大，制作前需对号入座：

| 平台 | 素材形态 | 推荐分辨率 (px) | 宽高比 | 体积与格式限制 | 核心注意点 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **Twitter (X)** | **个人页 Header 封面** | **`1500 x 500`** | 3:1 | PNG / JPEG $\le$ 2 MB | 左下角有圆形头像遮挡区，核心内容偏右居中 |
| **Twitter (X)** | **推文单图 (Post)** | **`1200 x 675`** | 16:9 | PNG / JPEG $\le$ 5 MB | 信息流中最舒适的展示比例，不被自动裁剪 |
| **Twitter (X)** | **推文动图 / 视频** | **`1200 x 675`** 或 `1080 x 1080` | 16:9 / 1:1 | MP4 / GIF $\le$ 512 MB | 推荐 15~30 秒短循环，前 3 秒出视觉高潮 |
| **TikTok / 抖音** | **竖屏宣传短视频** | **`1080 x 1920`** | 9:16 | MP4 $\le$ 500 MB (TikTok) | 严格遵循右侧交互栏与底部文字安全区避让 |
| **TikTok / 抖音** | **视频封面图 (Cover)** | **`1080 x 1920`** | 9:16 | JPEG / PNG | 大字标题位于垂直中间 30%~70% 黄金区 |
| **Reddit** | **帖子信息图 / 动图** | **`1200 x 675`** 或 `1080 x 1080` | 16:9 / 1:1 | PNG / JPEG / MP4 | 拒绝过度包装广告，偏好纯技术/真实对比图 |
| **Reddit** | **板块顶部 Banner** | **`1920 x 384`** (大) 或 `1200 x 300` | 5:1 / 4:1 | PNG / JPEG $\le$ 5 MB | 扁平极宽，文字必须水平居中 |

## 二、 关键平台安全区与排版法则 (Safe Zones)

### 1. TikTok / 抖音 9:16 竖屏安全区避让（重中之重）
手机端播放界面有大量的原生 UI 浮层，关键图文切勿踩入雷区：
* **顶部避让区（留白 15% / 约 280px）**：避开手机状态栏、搜索按钮和推荐/关注 Tab；
* **底部避让区（留白 20% / 约 380px）**：避开作者账号名、文案描述、音乐转盘和底部导航；
* **右侧避让区（留白 15% / 约 160px）**：避开头像、点赞红心、评论、收藏和分享按钮；
* **黄金内容区**：所有文字标题、手机与大屏演示画面，必须收拢在**垂直方向 20% ~ 75% 之间**。
* **推荐排版（经典三段式）**：
  * 顶部（20%~35%）：醒目大字痛点标题（如“闲置平板秒变商业餐牌”）；
  * 中部（35%~70%）：分屏双机画面（手机拖拽 + 电视大屏同步变化）；
  * 底部（70%~80%）：特性小标签（免云端、无账号、离线可用）。

### 2. Twitter (X) Header 1500x500 安全区避让
* **左下角遮挡**：个人圆形头像会在左下角占据约 `400 x 400` 的重叠区域；
* **法则**：所有品牌 Logo、产品标语、设备样机必须集中在**画布的中间偏右侧**。

## 三、 各平台调性与审核/运营注意事项 (Community Guidelines)

- [ ] **TikTok / 抖音【前 3 秒黄金钩子 (Hook)】**：
  * 用户划走极快，前 3 秒严禁放漫长片头；
  * 必须一上来就展示痛点或反差（如“别再买几千块的广告机了”、“断网也能播的秘密”）。
- [ ] **Reddit【反硬广 / 偏好真实硬核 (Authenticity)】**：
  * 在 r/SideProject, r/selfhosted, r/Android 等技术社区，过度商业吹嘘会被踩灭或删帖；
  * 应该以“独立开发者做了一款 Local-first 广告机”、“拒绝昂贵 SaaS 云端月费”为真实角度交流，配以技术架构图或真实运行截图。
- [ ] **Twitter (X)【Build in Public 与极简对比】**：
  * 适合发布 15 秒极短视频动图，配上对比文案（左边 Web 操作，右边大屏秒变）；
  * 多使用话题标签（如 `#indiehackers` `#androiddev` `#digitalsignage`）。

## 四、 动态协作与内容插槽 (Content Collaboration)

具体的文案话术、视频脚本、展示行业与产品画面，在创作时按需动态填充：
* **创意插槽**：小老板省钱视角（小餐饮/零售）、技术极客离线自愈视角（拔网线测试）、场景氛围视角（咖啡厅电子水牌）；
* **多语言适配**：国内平台（抖音、B站、小红书）输出中文版；国际平台（Twitter、TikTok、Reddit）输出英文版；
* **协作方式**：向 AI 提出特定平台的诉求（例如：“我想在 TikTok 发一条给奶茶店老板看的 20 秒短视频脚本”），AI 将在符合上述平台尺寸与安全区规范的基础上，生成贴合该平台调性的文案与分镜。
