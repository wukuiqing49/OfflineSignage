# 页面体验与样式优化记录

更新：2026-10-21。范围：Android 展示端、方向设置契约与虚拟机页面回归。

## 样式分析与设计决定

| 原有表现 | 对使用体验的影响 | 本次处理 |
| --- | --- | --- |
| 欢迎页品牌标签被动态放大，主标题被缩小 | 首屏重点颠倒，横屏显得零散 | 品牌标签12sp，标题28/36sp，正文14/17sp；介绍可完整换行 |
| 连接页授权位于二维码上方，企业联系与连接信息同级 | 首次扫码时受到次要操作干扰 | 核心内容只保留二维码、地址、配对码与网络；授权和联系移到独立次级操作区 |
| 帮助页全部按钮纵向排列，横屏留白大 | 查找主题需要较长滚动 | 发布内容、管理屏幕两个主题组；宽屏并排，窄屏和大字体上下排列 |
| 授权页状态、权益、操作纵向堆叠 | 横屏操作被推到下方，刷新整页闪空 | 状态/权益与操作分栏；保留状态内容，增加明确重新加载入口 |
| 普通页面颜色与按钮形状各自设置 | 同一产品的视觉一致性弱 | 欢迎、帮助、授权、法律页共享绿色品牌和日夜色板，统一8dp圆角、至少48dp按钮 |

固定展示的连接页继续采用深色背景，二维码使用纯白底；普通管理页面遵循系统日夜主题。两种场景共享绿色强调、间距和组件语义。播放画面继续由用户内容决定配色。

## 布局规则

- 双栏内容根据真实可用宽度与字体缩放决定，普通页面阈值760dp；连接页阈值560dp。字体放大时优先堆叠，不缩小文字掩盖溢出。
- 页面可滚动；系统栏/刘海 Insets 仍由各页明确消费。底部操作通过滚动完整可达。
- 二维码在紧凑窗口为144dp，普通窗口为240dp；连接内容最大宽度1040dp，并居中。
- 手动打开的连接面板在 Activity 重建时恢复；布局变化不强制把滚动位置重置到顶部。
- 帮助按钮保留原有入口与资源 id；长标题自然换行，点击目标至少48dp。

## 方向与设置契约

- 未保存方向的新设备默认 LANDSCAPE。已有 AUTO/PORTRAIT 选择继续有效。
- 单窗口下，Android 15及以下平板与手机都尊重显式方向；AUTO 跟随系统。
- Android 16+ 大屏（最小宽度至少600dp）及多窗口交由系统管理，页面自适应实际窗口。控制台设置页提供说明。
- 依据：[Android 官方方向与尺寸调整说明](https://developer.android.com/develop/adaptive-apps/guides/app-orientation-aspect-ratio-resizability)。不添加临时兼容模式退出开关。
- POST /api/settings 只更新提交字段，未提交方向/常亮/恢复/全屏/fallback 保留原值；显式 null 可以清空 fallback；非法方向与字段类型返回400，不静默回退。
- 参数合并与校验提取为 SignageSettingsPatch，减少 HTTP 路由内职责。

## 三档套餐开放后的布局调整

按用户要求恢复月度、年度、永久三档新购入口后，授权页改为状态/权益在上、套餐使用完整内容宽度，宽屏三卡并排、窄屏和大字体纵排；取代上文单年付阶段的左右双栏。不可用商品保留卡片与价格不可用提示，购买按钮禁用。验证见测试报告最新节。
