# Local Signage 真机功能与国际化验收（2026-09-18）

## 环境与范围

- 真机：OPPO PCAM00，Android 11 / API 30，1080×2340，480 dpi。
- 保留原有应用数据，通过同签名覆盖安装进行测试，没有清空应用或购买商品。
- 系统原始语言 zh-CN，字体 100%。通过 AppCompat 的应用语言测试配置覆盖 en、zh-CN、de、es、fr、ja、ko、pt；系统语言保持不变。
- 手机实际最大字体档为 160%，通过系统“字体与显示”页面设置。测试结束须恢复 100%。
- 页面巡检记录 Android TextView 的真实排版、省略字符数、内容高度、可见区域与当前资源语言，并保存页面顶部/底部截图。不是只对 XML 或字符串长度做静态判断。
- 证据保存在忽略的 `build/device-qa/`。配对页原始截图包含短期配对凭据，不应提交仓库或公开传播。

## 已复现并修复的问题

| 问题 | 原因 | 修改 |
| --- | --- | --- |
| 设备中心底部按钮裁切、无法完整滚出 | 卡片被固定为屏幕高度，内部内容超出测量边界 | 卡片使用内容高度和最小屏幕高度，内容区取消高度权重，交给外层 ScrollView 滚动 |
| 德语企业支持按钮被挤成多行碎片 | 很长的翻译放在仅 144dp 宽的二维码列 | 按钮移到较宽的连接信息列，保持完整文案和触控入口 |
| 配对提示、网络状态、地址和热点文案截断 | 固定行数或固定按钮高度 | 说明文字自然换行、按钮使用最小高度而非固定高度 |
| 授权状态在大字体下显示为省略号 | 144dp 列内授权状态强制单行 | 授权状态可换行，整行高度随内容增长 |
| 英/德/法/西/葡的长帮助标题被省略 | Toolbar 默认单行，且固定 56dp 高度 | 共享标题换行设置，Toolbar 改用最小高度；窄屏正文仍可滚动 |
| 购买方案在大字体下存在列宽风险 | 根据整屏宽度而非内容区宽度选择三列 | 按真实容器宽度和字体比例决定横排/竖排；本机无法加载 Google Play 商品，真实价格目录尚未验收 |
| 欢迎页按钮的放大字体裁切风险 | 固定 56dp 高度 | 改为 wrap_content + minHeight；在隔离安装的测试副本中完成中文首次引导验证 |
| 上传后的中文、日文等文件名被替换为下划线 | 存储显示名直接复用安全磁盘名 | 分离用户显示名和 ASCII 安全磁盘文件名，保留原始 Unicode 显示名 |
| 媒体下载不能按字节范围续传 | 媒体路由未启用 HTTP Partial Content | 为受鉴权的媒体路由启用分段响应，真机验证 206 与 416 |
| Web 控制台切换中英文后设备名和在线状态未即时更新 | 重绘时只更新了局部目标选择控件 | 每次动态重绘同步全局目标选项和连接状态 |
| Android TV 初次进入页面没有明确遥控器焦点 | 外层 ScrollView 可抢占焦点，页面没有主动请求首个可操作控件 | 电视模式下关闭外层滚动容器焦点、设置配对/播放/帮助/法律/购买页面首焦点，并验证 D-pad 确认键进入帮助 |

## 页面测试记录

- 第一轮 8 种语言 × 34 个页面状态 = 272 个状态，全部使用手机真实 160% 系统字体。
- 覆盖：设备中心；帮助目录；9 类帮助文章；购买页的 Google Play 不可用状态；法律目录；4 篇法律文档。每页检查顶部与滚动到底部。
- 第一轮发现长标题及授权状态省略；日语、韩语、中文没有触发这些省略问题。
- 第二轮针对修复后的关键页面，在 8 种语言、160% 字体下补充竖屏窄宽度巡检。设备中心按产品要求保持横屏，其他页面切换竖屏。
- 第二轮结果：8 种语言 × 14 个关键页面状态 = 112 个状态，实际 160% 字体下均为 0 个省略和 0 个垂直溢出。设备中心为横屏，其余页面为竖屏窄宽度。
- 隔离测试副本的内容与播放回归：61 项通过，0 项失败，覆盖图片、视频、Unicode 文件名、HTTP Range、播放/暂停/续播、资源保护和清理。
- 隔离测试副本的高级内容与编排回归：32 项通过，0 项失败，覆盖多语言文字、HTML、网页、HLS、场景叠加、播放列表、定时轮播和冷启动恢复。
- 原有应用的受限授权回归：44 项通过；2 项上传测试因既有资源数已达免费版上限而按预期跳过。原有 23 个资源和 4 个播放列表保持不变。
- 最终正式包已覆盖安装回原应用，SHA-256 为 `BAA3E0B53E70DC9F897AD652C392284A007DE603D14BA43DE7C1FCC99A64C698`，系统字体已恢复 100%。
- Google TV Android 36 AVD（1920×1080）复测：欢迎页、配对页和主页面布局通过；D-pad 可移动到企业支持按钮，确认键可进入帮助文章，帮助操作按钮获得焦点。正式版重新构建成功；真实厂商电视盒子仍需验收。

## 国际化边界

- Android 原生字符串提供 8 种语言。
- Web 控制台目前完整提供中英两种语言，其他语言菜单明确标注 English fallback；不能把这理解为 Web 已完整翻译为 8 种语言。
- 法律正文目前只有中文和英文资源，其他语言回退英文；原生目录和标题已翻译。法律正文翻译和法律审阅不在本轮自动修复范围内。

## 不能由本机验证的项目

- Google Play 真实商品加载、试用开通、支付、续订、退款、跨设备权益恢复。
- 双广告机发现、同步、失联补偿，以及厂商电视/平板差异。
- Android 15/16 的强制 Edge-to-edge、开机前台服务策略、16KB 系统页环境。
- 24/72 小时持续播放、断电恢复和长期存储稳定性。
- 当前原有应用试用已结束，专业功能的 HTTP 接口应拒绝新增高级内容；未修改原有授权状态绕过付费限制。高级内容验证在同签名、独立包名的全新测试副本中完成，并在结束后卸载。

## 复跑页面巡检

测试 APK 使用项目内的 `DeviceUiAudit` Instrumentation，无额外运行时依赖。

```powershell
.\gradlew.bat :app:assembleDebug :app:assembleDebugAndroidTest
adb install --no-incremental -r app/build/outputs/apk/debug/app-debug.apk
adb install --no-incremental -r app/build/outputs/apk/androidTest/debug/app-debug-androidTest.apk
# 先在手机上设置字体，并保持解锁、关闭通知栏及安装器。
adb shell am instrument -w -e locale de -e fontScale 1.6 -e orientation portrait -e mode compact com.wkq.localsignage.test/com.wkq.localsignage.DeviceUiAudit
```

`fontScale` 是对实际系统字体的校验值，不会替调用者修改系统设置。省略 `mode compact` 时巡检全部帮助与法律页面。报告与截图位于应用 external files 的 `device-ui-audit` 子目录。巡检结束恢复原应用语言；调用者仍需恢复自行调整的系统字体。
